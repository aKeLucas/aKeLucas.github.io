## Rodando localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```
2. Abra a pasta no VSCode.
3. Com a extensão **Live Server**, clique em "Go Live" para abrir o site.

Também funciona abrindo o `index.html` direto no navegador.

## Foto de perfil

Salve a foto como `assets/img/foto-perfil.jpg`, em proporção 4:5 (por exemplo, 800 × 1000 px). Se o arquivo não existir, o site mostra as iniciais no lugar.
